# E01 v0.6.0 冻结验收要求

## 共同交付与不可省略的验证

拟新增目录分别为 examples/dynamics_loaded_arm、dynamics_screw_stage、dynamics_flywheel_brake、dynamics_pendulum_buffer、dynamics_loaded_column。每个目录后续交付 requirements.md（冻结命题）、verify_case.py（先写、独立于建模参数生成器）、model/build_cadir.py、.scadpkg、物性 manifest、verification.json、含证据的 .kincheck 及运行 README。本轮不创建这些代码文件。verifier 从导出的包读取真实几何/接口/物性与实际结果，不能直接引用 build 脚本的内部变量作为“实测”；解析预期可以使用冻结需求中的常数和独立推导。

统一 Z 向上，CAD 长度 mm，运动/动力学 SI；密度来自 CADIR 材料，m/c/I_C 按[转换层文档](v0.6.0-cadir-physics-bridge.md)计算。下列默认金属为演示用均匀钢 7850 kg/m³；需要减重件时显式指定铝 2700 kg/m³。弹性演示钢 E=210 GPa、ν=0.30、屈服 355 MPa、极限 550 MPa；这些是人工设计输入，不代表任意命名钢材的实测性能。聚合物缓冲件体密度预设 1100 kg/m³，刚度/阻尼单独标注 illustrative，不能由密度推导。所有结论记录 data_quality 和假设适用范围。

每件有唯一 occurrence ID、材料、实体体积、连接接口、支承链、BOM 数量和后端组归属。表中的重复件均按实例计重。底板安装到显式环境安装面；地面质量不当成机构有效载荷。驱动器转子/轴与定子分开，若用厂家惯量覆盖转子几何，必须只计一次且记录覆盖来源。螺栓必须穿真实孔、有头部/垫圈/螺母或有明确攻丝深度；轴有轴肩、定位/止退件；护罩也须有支脚与紧固。实体的孔、倒角、圆角、键槽和驱动螺纹要建模，不能只给中心线、包围盒和贴图。非关键边默认 R1 或 C0.5，功能孔不得被圆角吞掉；名义尺寸配合要预留明确间隙，避免实体相互穿插。

接口至少包括 interface.mount、interface.bearing、interface.axis、interface.fastener、interface.load、interface.contact、interface.guard，且关联真正的 face/region。运动刚体聚合不吞掉内部实体检查。全部 N(N−1)/2 物理配对必须有“连续检查/固定相对姿态初态精查+不变性/允许接触局部面/环境外部范围”的明确归宿，覆盖不能靠少列 pair 得到。

自由面最低间隙 0.10 mm、防护与运动件间隙至少 5 mm；小配合间隙用单独更严格的网格/距离误差预算。几何近似与查询误差之和最多占被证明间隙的 1/3，否则加密或不确定。螺纹、落座、销轴和支承只在明确界面允许功能接触，不能排除整个组件对。拓扑连到地面只是第一层；载荷下不脱离/不滑移/不倾覆和变形后不碰撞还须相应动力学/结构证据。

每例 verifier 顺序为：包/几何有效性与 BOM → 材料及三元组转换 → 全实体连接/安装 → 初态间隙 → 计划运动与限位 → 连续几何 → 本阶段动力学 → 实际轨迹/变形后的几何复验 → 载荷/能量/收敛 → JSON/.kincheck 往返。缺少后续版本能力时，只能发布已覆盖子命题，整套未覆盖工况不得 passed。输出“是否通过、发生什么、原因、如何修复”、对象、时间、实际/目标、单位和证据；失败 CLI 返回非零。故障变体必须被独立 verifier 检出，测试框架可以因成功检出而通过，但故障模型本身的工程结论仍是 failed。

## E01 带载摆臂与双支承转轴

目的：0.6.0 静力/重力/偏载，0.6.1 加速需求与驱动选型，0.6.2 有限电机下的跟踪。拟目录 dynamics_loaded_arm。

| 实体与数量 | 几何、位置和实际连接 |
| --- | --- |
| 底板 ×1 | 360×220×16，X 范围 −40…320、Y=±110、Z=0…16；四个 Ø9 安装孔在 (−25,±85)、(300,±85)，实际 M8 螺栓/垫圈锁到环境安装面 |
| 支座 ×2 | 立板 X=−25…25，Y=34…66 及 −66…−34，Z=16…285；每块底脚 80×50×12 与底板落座，四个 M8 安装点；轴孔同轴，中心 (0,±50,260)，沿 Y，孔 Ø24.2，孔边保留足够壁厚 |
| 轴、衬套、止推/锁紧件 | 轴 Ø16、Y=−85…85、中心 X=0/Z=260；两衬套 OD24、ID16.2、长32，分别穿两支座；轴肩/止推垫圈/锁紧环布置在支座外侧，不能压进支座实体。衬套与座固定，轴相对衬套转动；所有轴向间隙逐面记录 |
| 摆臂 ×1 | 零角沿 +X；根部 Ø48、宽28 的轮毂及 Ø16.2 轴孔，带真实键槽/夹紧螺栓；臂管局部 X=24…276、截面 Y40×Z60、壁厚4；末端实心连接块 X=276…300。轮毂到方管有实体连接/过渡圆角，不能相离 |
| 载物平台、负载块 | 平台局部 X=260…340、Y=±40、Z=30…40，落座在末端连接块上，以4个沉头 M6 固定（X=282/294、Y=±10），头部与上表面齐平；负载块底面落在平台顶面，平面80×60，4个 Ø6.6 通孔位于其中心±25/±20，对应平台顶面深8的盲螺纹孔，螺钉不得伸入下方臂管。选择钢块高度，使扣除通孔后的实体质量为2.000 kg（±0.1%）；以 h=2/[7.85×10⁻⁶(80×60−4π×3.3²)] mm 为初始解，倒角后再独立核验/调整高度 |
| 电机、联接和防护 | 定子固定在负 Y 支座外侧的实体安装架上，转子通过同轴联接/键与主轴连接，孔位与紧固件完整；外侧联轴器罩与电机架固定，内壁距转动包络≥5。厂家转子惯量与几何积分明确择一，不双计 |

未注明的摆臂局部 Z/Y 以转轴中心为原点。公共关节轴取 −Y，θ=0 臂水平，θ>0 上举；允许范围 −20°…60°。正常轨迹 0°→45° 用2 s C²段，停1 s，2 s返回，停1 s；全程速度/加速度/连续性按 profile 实值核验，不靠名称保证。平台与负载的姿态随摆臂转动，这是绑紧负载，不能当作自由放置物体。

静力子工况分别取0°/30°/60°，重力 (0,0,−9.81) m/s²；空载移除负载块并同步更新 BOM，额定2 kg，超载3 kg使用另一高度的实体负载块。偏载在负载接口局部 (0,40,0) mm 施加世界 −Z 方向100 N，通过刚性加载耳片传入平台；耳片本身有实体和螺栓，且计重。输入额定/短时扭矩暂定20/35 N·m，短时限2 s；这只是需求阈值，须按实际模型算后决定是否合格。

验证：按实际各实体质心与施力点独立求关于主轴的重力/外载力矩，静力误差≤max(0.02 N·m,1%)；两支座只能先验证总合力/矩，未提供柔顺性不能编造各自分担。逆动力学增加真实轴惯量项并验证机械能；正动力学检查角跟踪误差≤0.5°、实际角度不越界、实际运动不干涉。反例至少有漏负载密度、键/支承脱离、孤立锁紧环、负载质量双计、电机扭矩不足及护罩压入运动包络。


## 冻结数值预算

质量相对容差 1e-8、绝对 1e-10 kg；质心绝对 1e-10 m；惯量相对 1e-8、绝对 1e-14 kg·m²。静力平衡 0.01 N / 0.001 N·m。解析力矩 max(0.02 N·m, 1%)。仅验收 0°/30°/60° 静态姿态，不宣称连续运动、接触稳定、结构强度或动态驱动能力。额定 20 N·m 超限是 failed，不调整模型质量或阈值隐藏事实。

The saved output includes rated, empty and overload manifests/results under `output/variants/`; the main `output/verification.json` is the rated case. A rating check failure remains an engineering failure even when geometry, mass conversion and static equilibrium pass.
