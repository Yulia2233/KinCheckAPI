# 证据和通过规则

一个 Agent 只有在以下条件都满足时才能说“通过”：

- 输入和检查参数是有限值，范围合法；
- 装配和场景预检通过；
- `MotionResult.status` 不是 `partial`，且有实际采样；
- 对应检查的实际样本、组件对、测量数量大于零；
- `issues` 中没有未处理的 error 级问题；
- 证据值满足用户给出的阈值；
- 检查范围和排除项与用户意图一致。

验证程序应调用结果对象的 `raise_if_failed()`（或等价的 `diagnostics.assert_check_passed()`），让 CLI 以非零退出表示失败。控制台输出至少保留 `passed`、`status`、计数、阈值、最大/最小观测值和问题代码；只有用户明确要求时才额外持久化报告。

验收条件必须先于 SimpleCADAPI 模型实现写入验证程序。除非用户改变验收命题，不得为了让当前模型通过而放宽阈值、删减检查、减少采样或增加无依据的排除项。
