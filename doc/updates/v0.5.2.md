# v0.5.2: SimpleCADAPI addon integration

## Compatibility boundary

The existing `convert_mjcf()` signature, `AdapterResult`, `AssemblyModel`,
Scenario setters, solvers, checks and `verify(model_dir)` contract are unchanged.
No solver settings, physical thresholds, sampling rules or example modeling
parameters were modified. The library's base dependencies remain unchanged.

The deliberate CLI correction is that a verifier returning `None`, an arbitrary
value, a non-mapping `to_dict()` result, or no explicit verdict no longer becomes
a successful verification. Explicit boolean and structured verdicts remain
supported, and failed/partial verdicts retain nonzero exits.

## Addon integration

- `sca-addon.toml` declares the `kincheckapi` addon, Apache-2.0 license, Python
  runtime, macOS arm64 platform and the exact runtime probe.
- Optional `kincheckapi[addon]` adds SimpleCADAPI and version-range validation in
  an addon-owned environment, separate from modeling.
- `kincheckapi.addon.prepare_package()` and `kincheck prepare-package`/
  `verify-package` accept a finished `.scadpkg`, enforce the runtime probe,
  validate it and produce a fresh work directory for existing MJCF consumers.
- The major-version gate precedes member parsing; SDK validation covers schemas,
  manifest/member hashes and graph closure. Topology payloads resolve by SHA256
  through manifest storage records, not logical filenames.
- Required `interface.*` names are scoped by exact part occurrence IDs. Missing
  names fail explicitly. Multiple named entities and repeated part occurrences
  retain their identities, revisions, hashes and coordinate data.
- Source packages remain read-only. Exported MJCF must also pass the original
  conversion/compiler/topology gate before preparation reports success. Derived
  meshes and STL caches remain under the addon's work directory.
- English, Chinese and wheel-bundled skills include the runtime gate, source
  format reference, units, coordinate conventions, main-skill handoff and capture
  lifecycle. Legacy portable skill archive names remain supported.
- `scripts/package_addon.py` stages a clean repository without virtual
  environments; the source distribution includes descriptor and skill files.

## Paired SimpleCADAPI fix

This development release requires the sibling CADIR source at `2.1.3b2`, with
compatibility range `>=2.1.3b2,<2.1.4`. Development lockfiles record that source;
distribution metadata retains the version range. Do not install an unpatched
`2.1.3b1` runtime or assume this prerelease has been published to a package index.

Real four-bar package testing found that the upstream MJCF exporter treated
canonical integer ticks in occurrence/connector frames as millimeters. A 20 mm
offset consequently became 20,000,000 m instead of 0.02 m. The paired SDK fix
uses its existing canonical placement decoder at those boundaries. Scene entity
frames, already in millimeters, retain their old interpretation. Public exporter
signatures, geometry and simulation settings are unchanged.

## Verification results

Before changes: 657 existing tests passed. The core environment, without the
optional SDK, subsequently passed 688 tests and skipped the optional integration
module. Final verification in the separate addon environment, including the SDK
coordinate regression tests and a re-captured four-bar package: **711 passed**.

The descriptor probe was measured in three fresh macOS arm64 processes at
approximately 1.19, 1.28 and 1.39 seconds. Add/list/update/remove and install-time
probe warnings were exercised using temporary addon homes and copied skills;
registry entries reported empty drift lists. No global skill registration or
remote publishing was performed.

| Existing example | Observed result |
| --- | --- |
| Optimized four-bar, original native solver | `completed`; ten-second crank travel approximately 6.283153730237 rad; sampled closure-position residual approximately 3.94e-11 m. |
| Optimized four-bar, reference geometry checks | 301 frames, zero interference events, including the existing non-adjacent-pair check. These are reference-trajectory samples, not a continuous-time collision proof. |
| Original four-bar, expected failure | 301 frames, 1,358 interference events; maximum penetration approximately 0.600000145 mm. |
| Three-stage planetary reducer | Existing 64:1 check fails with `KINCHECK-CHECK-RATIO-INSUFFICIENT-SAMPLES`; the stored MJCF conversion has no couplings and no valid output-speed ratio samples. |
| Compact two-stage planetary reducer | Existing 20:1 check fails with `KINCHECK-CHECK-RATIO-MISMATCH`; observed median ratio approximately 2.1714e11. |

The two planetary example failures occur on the unchanged legacy API path. Tests
preserve these failure verdicts; a green regression suite does not mean those
mechanisms pass their acceptance requirements. Their source/model export needs
separate investigation rather than relaxed thresholds or altered solver behavior.

All four archived product packages (the planetary examples and both four-bar
variants) use old placement encodings rejected by the current SDK. They were not
rewritten or re-signed. For the positive package test, the optimized four-bar's
unchanged modeling sources were copied into an isolated modeling environment and
captured anew. The new addon API and `verify-package` CLI both consumed that
package successfully; CLI evidence reports `passed`, native `completed`, 101
samples and crank travel 6.283153730237362 rad.

## Reproduce locally

From the CADSimAPI repository with sibling CADIR checkout:

```bash
uv venv --python 3.12 .venv-addon
uv pip install --python .venv-addon/bin/python -e '.[addon,test]' -e ../CADIR
.venv-addon/bin/kincheck doctor --addon --format json
KINCHECK_TEST_SCADPKG=/absolute/path/to/recaptured/four_bar_linkage.scadpkg \
  .venv-addon/bin/python -m pytest tests ../CADIR/test/test_mjcf_tick_frames.py -q
```

Use the main SimpleCADAPI modeling workflow in a separate environment to
re-capture examples. The acceptance program continues to consume only its
prepared model directory. SDK and platform support may be widened only after
corresponding tests; only macOS arm64 is declared for this addon release.
