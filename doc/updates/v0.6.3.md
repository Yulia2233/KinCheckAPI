# KinCheckAPI v0.6.3 更新

v0.6.3 增加可审计的接触/摩擦承载能力检查。`ContactSpec` 显式声明接触法向、摩擦系数、接触面积、允许法向力和允许压力；`check_contact_capacity()` 将外部力分解为法向分量和切向分量，检查分离、库仑摩擦锥、法向载荷和压力，并返回每项利用率与结构化失败原因。法向量约定为压缩载荷方向，单位为 N、Pa 和 m²。

E01 新增 `examples/dynamics_loaded_arm/verification/verify_contact.py`，验证平台导向接触的 10 N 法向、1 N 侧向载荷，以及摩擦、法向力和压力预算。该例与 CADIR 接口/静力程序分开运行，便于定位几何、物性、载荷和接触容量问题。

本版的接触 API 是给定外力的容量检查，不是接触力求解器，也不提供连续接触响应、碰撞冲量、恢复系数、接触变形、应力、振动、共振或疲劳寿命。非有限力、非单位法向、拉开接触或超出摩擦/压力预算都会以 `validation_failed` 或 `failed` 返回。
