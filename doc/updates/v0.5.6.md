# KinCheckAPI v0.5.6 更新说明

v0.5.6 实现了现有标量关节后端范围内的数值逆运动学。`solve_inverse_kinematics()` 现在可以接收一个静态 `PoseTarget`、初始关节值、有效关节范围和 `IKOptions`，通过前向位姿、有限差分 Jacobian 和阻尼最小二乘迭代搜索可行关节状态。

新增 `IKOptions`、`IKSolution` 和 `IKSolutionSet`。结果区分 `solved`、`unreachable`、`nonconverged`、`singular`、`invalid` 和 `capability_failed`；每个候选都保留初始值、最终关节值、位置/姿态误差、残差范数、迭代次数、Jacobian 秩、奇异值、限位状态和结构化 issues。`multi_start_count` 与 `random_seed` 提供确定性的有限多初始值搜索，候选按关节距离去重后再按 `first`、`lowest_residual` 或 `closest_to_initial` 选择。

所有候选解在返回前都会重新计算目标误差、闭环/传动残差和有效关节范围；未通过验证的迭代状态只能出现在 `attempts`，不会出现在 `solutions` 或 `selected_solution`。结果支持 `to_dict()`/`IKSolutionSet.from_dict()` round-trip。

本版本的 IK 明确限定为 `fixed`、`revolute`、`prismatic` 标量树关节。`PoseTrajectory` 驱动、spherical/free/planar/cylindrical 关节、碰撞约束 IK、时间最优 IK 和全局完备多解证明仍返回结构化 capability failure 或保留为后续能力。多初始值只能提高解发现率，不能证明不存在其他解。

测试覆盖可达目标、确定性多初始值、固定有效范围下的不可达目标、非法输入、PoseTrajectory 和 spherical Joint 能力边界、结构化诊断和结果 round-trip。发布前运行：

```bash
.venv/bin/python -m pytest -q tests/test_v056_ik.py tests/test_v021_position_geometry.py tests/test_v021_analysis.py
.venv/bin/python -m pytest -q
```
