# KinCheckAPI v0.6.0 更新

v0.6.0 打通 CADIR 材料密度与封闭 BREP 到可追溯质量物性和树形静力。新增 SI 单位的完整质心惯量张量、逐 occurrence 位姿、固定组平行轴聚合、payload 身份检查、按操作能力探针、强类型重力/载荷/支承契约、MuJoCo 显式惯量与编译反查、静态 BREP 全配对证据，以及 `.kincheck` 的可选 `physics.json`。

E01 带载摆臂包含真实安装孔、轴/衬套、键、夹紧件、重复紧固件、电机安装、护罩、加载耳片和空载/额定/超载负载块。冻结验证器覆盖 0°/30°/60°、每姿态 2,850 个实体配对、质量/来源哈希、静力平衡、独立保持力矩和额定值。100 N 偏载在 0° 有意超过示例 20/35 N·m 额定值；失败会保留在结果包中。

四连杆回归覆盖 9 个实体 occurrence（含重复销轴），BREP coupler 质量实测为 0.00845756965721357 kg；历史仅密度网格推导为 0.020575503688623036 kg。当前 CADIR 2.1.3b3 会拒绝旧 placement 编码；旧包必须显式选择隔离的 2.0.4b3 读取器并记录 SDK，不猜比例、不绕过校验。

本版不宣称逆/正动力学、接触响应、多余支承的单点反力分配、结构应力/变形、振动或疲劳；能力探针会明确报告边界。

## 复核修复

静力结果通过模型摘要和原始请求绑定；写出/读回重新求解，拒绝载荷、保持力、反力或残差不一致的结果，即使 ZIP 哈希被重算也会拒绝。显式实测 payload 往返保留原始物性、身份和来源，叠加前组件物性避免二次计重。静态 Viewer 独立计算案例数并直接使用静态位姿，直接导出路径补齐传动比单位。物理成员升级为 `kincheck.static/1.1`；没有绑定的开发版物理包须重新生成，旧运动学包保持兼容。
