# KinCheckAPI v0.1.1 更新报告

## 版本目标

本版本完成从 CadIR 装配文件到 KinCheckAPI 运动模型的三项关键修复，重点解决行星齿轮动画中“行星轮只自转、不随行星架公转”的问题，并补齐子装配体在运动模型中的表示。

## 主要更新

### 1. CadIR 姿态和连接点转换

- CadIR 的 `origin` 继续按长度单位转换为 KinCheckAPI 使用的米制 SI 坐标。
- CadIR 的 `x_axis/y_axis/z_axis` 现在会转换为 `Pose.orientation_xyzw` 四元数，不再统一假设零旋转。
- 几何面连接点会提取 `geo_selector.center` 作为连接点位置，并提取 `normal` 作为连接点 Z 轴。
- 支持几何连接点的 `flip` 标记；退化、非有限或无法组成正交基的方向会直接报错。

### 2. 内置物理后端 父子层级和真实关节轴

- 编译器现在使用显式关节图生成确定性的运动树。
- 子组件的 内置物理后端 body 会嵌套在父组件 body 下；父组件旋转时，子组件会继承父组件的平移和旋转。
- 每个树关节使用实际连接点位置作为关节枢轴，使用连接点局部 Z 轴作为关节轴，不再硬编码 `0 0 1`。
- 关节结果表达式改为“子端世界角度减父端世界角度”，适用于嵌套 body，不再把父关节角重复计算到子关节结果中。
- 非树关节仍保留为观测或齿轮传动约束；闭环选择树边是确定性的，并且不依赖组件名称。

### 3. 子装配体展开

- CadIR 的嵌套 Assembly definition 会递归展开为叶组件。
- 顶层实例保留原来的公开组件 ID，例如 `cmp.pg2.aux.input_bearing`；同一子装配体的其他叶组件使用稳定的路径 ID，例如 `cmp.pg2.aux.input_bearing/inner_ring`。
- 子装配体的 forwarded connector 会转换成真实叶组件上的接口连接点，顶层约束会自动重定向到该接口。
- 子装配体内部的关节会生成唯一的带路径 ID。
- 没有任何内部运动约束的叶组件会通过适配器生成固定关系，跟随该子装配体基准，避免被 内置物理后端 当作无意义的自由旋转体。该关系标记为 `adapter_generated=true`，便于诊断。

## 行星齿轮 ex2 的结果

- 第一级行星轮初始中心为 `11.25 mm`，并在运动过程中保持该轨道半径。
- 行星轮的 XY 位置会随行星架改变，行星轮不再固定在世界坐标中。
- 行星轮的 Z 方向位置保持不变，符合当前模型的平面行星传动假设。
- ex2 的 `20:1` 输入/输出传动比验证仍然通过。
- 轴承子装配体从顶层占位组件变为可寻址的内部叶组件。

## 测试覆盖

本版本为每个新特性各增加 8 个测试用例：

- `tests/test_cadir_pose_conversion.py`：单位、四元数、几何中心、法向、翻转和退化输入。
- `tests/test_integration_hierarchy.py`：body 嵌套、真实枢轴、非 Z 轴、相对关节表达式、行星轨道和传动比。
- `tests/test_cadir_subassemblies.py`：递归展开、稳定 ID、接口重定向、接口偏移、刚性随动和模型完整性。

原有测试保持通过；完整测试命令为：

```bash
uv run pytest -q
```

## 当前边界

- 这是运动学层修复，不等于完整动力学证明。
- CadIR 没有为所有子装配体叶组件声明运动关系时，适配器只能把未约束叶组件作为刚性随动部分处理。
- 内置物理后端 的闭环约束仍采用确定性生成的树加约束表达式；如果未来需要严格求解复杂闭环，需要继续扩展闭环约束编译器。
