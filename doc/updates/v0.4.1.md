# v0.4.1 更新记录

## 版本目标

v0.4.1 将 CADIR 到 KinCheckAPI 的运行时输入统一为一条路径：

```text
CADIR MJCF XML + scene.mapping.json + mesh assets
    -> kincheckapi.cadir.convert_mjcf()
    -> AssemblyModel -> Scenario -> solve_motion()
```

旧的 CadIR Artifact 目录及其转换入口已删除。这是一个明确的 breaking change；
`.scadpkg` 仍可作为 CADIR 产品源，但必须先由 CADIR exporter 生成 MJCF、mapping
和网格目录，不能直接作为 KinCheckAPI 运行时输入。

## API 变化

保留的唯一 CADIR 转换入口：

```python
from kincheckapi.cadir import convert_mjcf

converted = convert_mjcf(
    xml_path="examples/ex8/model/scene.xml",
    mapping_path="examples/ex8/model/scene.mapping.json",
    asset_root="examples/ex8/mjcf",
)
assembly = converted.assembly
```

删除 `CadIRArtifact`、`ArtifactFile`、`read_artifact()`、`validate_artifact()`、
`convert_artifact()`、`convert_live_assembly()`、`ArtifactValidationError` 及其
专用 assembly 展开 helper。`AdapterResult` 只保留 `assembly` 和 `source_map`；
运动结果包的 `MotionPackageArtifact` 与 Viewer 的 `ViewerArtifact` 属于输出层，
不属于已删除的输入路径，继续保留。

## 示例和目录

ex1–ex11 的运行时输入统一放在各自的 `model/` 目录，包含 `scene.xml`、
`scene.mapping.json` 和 `meshes/`。ex12 拆分为 `model/` 输入目录和 `output/`
结果目录。示例脚本、实例脚本、workspace exporter 和 clearance 业务场景均直接
调用 `convert_mjcf()`，不再生成、读取或回退到 `artifact/`。

MJCF 适配器现在也解析 `worldbody` 下的 public `site`，保留 closure site 的
source mapping、初始姿态容差、collision exclusions 和 mesh provenance；静态
fixture 中的网格均可被 clearance 契约转换和检查。根 XML 必须包含非空的
`model` 属性，并且必须与 mapping 的 `root_definition_id` 一致；缺失或不一致
都会以结构化 `KINCHECK-MJCF-MODEL-MISSING`/`KINCHECK-MJCF-MAPPING-INVALID` 失败。

## 测试变化

删除只验证旧 Artifact schema、manifest、hash、live snapshot、旧层级展开和旧
Artifact fixture 的测试文件；下游层级、公共 API、scenario、拓扑、位置几何、
齿轮齿条和示例回归测试均已迁移到 MJCF fixture。保留并新增：

- `tests/test_v040_mjcf_adapter.py`：MJCF 文件、mapping、mesh、source map、闭环和
  结构化失败回归；
- `tests/test_closed_loop_motion.py`、`tests/test_workspace_sweep.py`：转换后继续
  走通用运动学和 workspace 行为；
- `tests/test_v030_examples.py`：ex8–ex11 的几何安全业务结果。

当前验证结果：`663 passed, 5 skipped`。跳过项只要求本地未安装的 optional
`simplecadapi`，不影响 MJCF adapter 或 KinCheckAPI 核心回归。

## 迁移提示

调用旧 API 的代码需要改为显式传入三个路径：`scene.xml`、mapping JSON 和
`asset_root`。不要在应用层通过目录名猜测输入格式，也不要把 `.kincheck` 结果包或
Viewer 输出对象当作 CADIR 输入。历史 v0.4.0 文档保留当时“双路径共存”的记录，
当前行为以本更新记录和 `design/preupdates/v0.4.1.md` 为准。
