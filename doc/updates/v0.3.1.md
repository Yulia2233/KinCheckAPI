# v0.3.1 更新记录

## 版本定位

v0.3.1 修正结果可信性和数值验收协议。本版本不新增几何算法，也不改变 v0.3.0 的 FCL、真实三角网格、离散采样和运动包络能力边界。

## 已完成

### 1. Partial 结果统一为非通过

所有非几何检查在消费 `MotionResult.status="partial"` 时继续检查已有样本并保留时间范围、残差、事件和轨迹证据，但固定返回 `passed=false`、`severity="error"` 和 `KINCHECK-CHECK-MOTION-RESULT-INCOMPLETE`。几何检查继续返回 `ClearanceReport.status="partial"`，同时保留 v0.3.0 的兼容错误码。

`run_checks()`、`validate_closures()`、`find_singularities()` 和 Connector 路径检查继承相同语义。`SolveAttempt.status="partial"` 时 `succeeded=false`，`motion_result=None`，已记录前缀只保存在 `last_valid_result`。

### 2. 位置与方向容差分离

`solve_position()` 现在分别比较：

- `position_residual_m` 与米制位置容差；
- `orientation_residual_rad` 与弧度方向容差。

每个 `PoseTarget` 在显式设置容差时使用自身容差，否则回退到 `PositionSolveOptions`；多个目标互不放宽。失败报告记录残差、有效阈值、单位和目标 ID，并分别使用 `KINCHECK-KIN-POSITION-RESIDUAL-EXCEEDED` 与 `KINCHECK-KIN-ORIENTATION-RESIDUAL-EXCEEDED`。

可达性继承同一判定。工作空间样本分别保存 `residual_m` 和 `orientation_residual_rad`，方向超差的点不会计入可达集合。

### 3. 非法数值校验

公开检查阈值、PoseTarget、Closure、Coupling、JointLimit、PositionSolveOptions、ReachabilityOptions、WorkspaceOptions 和 SingularityOptions 均拒绝 `NaN`、正负无穷、非法负值、反向范围和非法采样数。

检查和分析入口将非法参数转换为结构化失败，不依赖 `NaN` 比较结果，也不返回空证据的通过报告。

### 4. Jacobian 奇异性分类

每个样本先执行绝对分类：零秩或没有有效正奇异值为 `singular`，最小有效奇异值达到奇异阈值为 `singular`，达到近奇异阈值为 `near_singular`，其余为 `regular`。之后再使用参考帧 rank drop 加重状态。

第一帧不再天然视为正常。零秩、首帧奇异、后续降秩和计算不可用样本都保留时间、秩、奇异值、条件数和结构化 issue。

## 测试

新增四组专项测试：

- `tests/test_v031_partial_checks.py`；
- `tests/test_v031_pose_tolerances.py`；
- `tests/test_v031_finite_parameters.py`；
- `tests/test_v031_singularities.py`。

专项测试覆盖正常、失败、边界、非有限值、重复运行和序列化证据。完整结果以发布时执行的 `uv run --extra test pytest -q` 输出为准；因缺少上游 `simplecadapi` 产生的 scadpkg 跳过项仍需在对应 CI 环境验证。

## 明确边界

本版本仍不提供连续时间无碰撞证明、BREP/NURBS 精确距离、接触力、摩擦、回差、磨损或碰撞动力学。`partial` 结果可用于定位失败和检查有效前缀，但不能证明完整工况通过。
