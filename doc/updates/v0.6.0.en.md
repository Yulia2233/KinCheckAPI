# KinCheckAPI v0.6.0 Update

v0.6.0 connects CADIR material density and closed BREP geometry to auditable mass properties and rigid tree statics. It adds explicit SI tensors, occurrence-preserving transforms, fixed-group parallel-axis aggregation, payload identity checks, capability probes, typed gravity/wrench/support contracts, explicit MuJoCo inertials with compiled readback, all-pair static BREP geometry evidence, and optional `physics.json` members in `.kincheck`.

The shipped E01 loaded-arm example contains real mounting holes, shaft/bushings, keys, clamps, repeated fasteners, motor installation, guard, load ear and calibrated empty/rated/overload payload variants. Its frozen verifier checks the 0°, 30° and 60° cases, all 2,850 physical pairs per pose, mass/source hashes, static force/moment residuals, independent holding moments and rated limits. The 100 N eccentric case intentionally fails the illustrative 20/35 N·m rating at 0°; the failed limit remains visible in the result package.

The four-bar conversion regression records all nine physical occurrences, including repeated pins, and reports BREP coupler mass 0.00845756965721357 kg versus the historical density-only MuJoCo derivation 0.020575503688623036 kg. Current CADIR 2.1.3b3 rejects the legacy placement encoding; an explicit isolated 2.0.4b3 reader is required for that historical package and records the chosen SDK. No placement is rescaled or bypassed.

This release does not claim inverse/forward dynamics, contact response, individual redundant bearing reaction sharing, structural stress/deformation, vibration or fatigue. `probe_dynamics_capabilities()` reports those boundaries explicitly.

## Review corrections

Static archives now bind every result to a model digest and saved request, re-solve on export/read, and reject inconsistent loads, holding efforts, reactions or residuals even if ZIP hashes are updated. Explicit measured payloads retain their original properties and provenance through round-trip; pre-payload component properties prevent double addition. Static viewers use a separate case count and exact static poses; direct exports now include transmission ratio units. Physics members use `kincheck.static/1.1`; unbound development physics packages require regeneration, while motion-only packages remain compatible.
