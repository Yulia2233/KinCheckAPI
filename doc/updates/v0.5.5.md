# KinCheckAPI v0.5.5 预备更新

本次更新补齐标量运动的 C 类验收闭环：PathTarget、PoseTrajectory 支持曲线、平面和位姿轨迹检查；check_start_stop_reversal、check_periodic_motion 和 check_synchronization 输出事件时刻、周期漂移、目标轴误差和首次失败采样点，并统一使用结构化诊断字段。

新增 ProfileBoundary.ERROR，profile 未从零时刻开始或在区间外求值时返回明确的场景/后端步进错误。后端步进失败会保留失败前已完成的采样，供 MotionSolveError 和 try_solve_motion 检查。

新增 motion_contracts 中的周期、多轴协调和位姿目标记录对象；周期目标会被明确采样成有限 position profile，多轴同步检查要求显式目标，不把最终位置误认为同步目标。当前后端仍只支持 fixed、revolute、prismatic 标量关节。6D 关节、连续时间 TOI 碰撞求解、笛卡尔驱动和通用多解 IK 继续返回明确 capability failure，不把位姿数据伪装成已实现的求解能力。
