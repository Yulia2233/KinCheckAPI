# v0.3.0 更新记录

## 版本定位

v0.3.0 把运动学仿真的“运动是否算出来”扩展为“运动过程中几何是否安全”。本版本继续使用 `AssemblyModel` 和 CadIR Artifact，暂不把 `.scadpkg` 运行时转换纳入范围。

## 已完成

### 1. 真实三角网格干涉检查

`kincheckapi.clearance.check_interference()` 使用 `trimesh` 读取 STL，使用 `python-fcl` 的 BVH 三角网格模型执行碰撞查询。网格必须是封闭且方向一致的实体；FCL 表面没有相交时，还会使用 `rtree` 支持的真实三角网格内外关系查询，覆盖一个实体完全包含另一个实体的情况。结果包含零件对、检查时间、接触位置、穿透深度、首个失败时间、采样范围和后端版本。

穿透超过 `penetration_tolerance_m` 时返回失败 issue `KINCHECK-CLEARANCE-INTERFERENCE-DETECTED`。不会使用包围盒、点云、球体或其他近似算法替代 FCL。

### 2. 最小间隙和安全阈值

`kincheckapi.clearance.measure_minimum_clearance()` 对每个零件对执行 FCL 距离查询，在整个时间窗口取最小带符号距离：正数表示有间隙，零表示接触，负数表示穿透。可用 `minimum_allowed_clearance_m` 做安全间隙验收，低于阈值返回 `KINCHECK-CLEARANCE-MINIMUM-BELOW-THRESHOLD`。

### 3. 真实网格运动包络

`kincheckapi.clearance.create_motion_envelope()` 把真实 STL 顶点按每个世界姿态变换，同时保存每个采样点的世界范围和全过程聚合范围。`check_envelope_interference()` 只报告包络重叠的可能性，并明确 `confirmed_mesh_interference=false`；失败或空包络不能重新得到通过结论。

### 4. 两种离散时间检查范围

几何检查支持：

- `sampling_scope="motion_result"`：检查公开 `MotionResult` 的组件姿态；
- `sampling_scope="solver_steps"`：检查 内置物理后端 每一次 `mj_step()` 后的组件姿态。

默认求解不保存积分步姿态。需要该检查时，先调用 `scenario.set_capture_integration_steps(..., enabled=True, component_ids=...)`，后端才把实际积分步姿态写入 `MotionResult.metadata["integration_samples"]`。可以只记录参与检查的组件，避免长仿真无条件保存所有组件。报告记录真实步数和步长。两种模式都只对实际离散样本负责，不声称连续时间数学证明。

只有 `status="completed"` 或 `status="completed_with_warnings"` 的 `MotionResult` 可以得到完整几何通过结论。`status="partial"` 的已有样本仍会生成碰撞、间隙或包络证据，但报告固定为 `passed=false`、`status="partial"`，并返回 `KINCHECK-CLEARANCE-MOTION-RESULT-INCOMPLETE`。

### 5. checks 统一入口

`checks.run_checks()` 新增 `interference`、`minimum_clearance`、`motion_envelope` 三种 `CheckSpec.check_type`。几何验收失败不会篡改 `MotionResult.status`，而是由 `CheckReport` 或 `CheckSuiteReport` 独立表达。

### 6. 严格单位和资产路径

Artifact 转换会保存源长度单位到米的 `mesh_scale_to_m`、`source_length_unit` 和 `asset_root`。几何查询在 FCL 建模前统一把网格顶点转换为米。NaN/无穷/负容差、缺失 STL、非封闭网格、未知或畸形零件对、空零件对、空包络组件选择、缺失或畸形轨迹、FCL 查询异常和后端不可用均返回结构化失败，绝不伪通过。显式组件对只加载参与检查的网格；`component_ids=None` 表示全部组件，显式 `component_ids=()` 不会扩大为全部组件。

### 7. 业务实例

- `examples/ex8`：带固定障碍物的曲柄滑块，演示安全和碰撞场景；
- `examples/ex9`：狭窄导轨滑块，实际 12 mm 小于业务要求 15 mm，演示预期的阈值失败；
- `examples/ex10`：带护罩的四连杆，区分闭环残差、包络重叠和真实碰撞；
- `examples/ex11`：轴承、螺钉和运动轴，演示显式碰撞排除不会影响其他零件对。

每个实例都包含 `artifact/`、真实 STL、`build_artifact.py`、`main.py`、`verify.py` 和中文 README。

## 明确边界

本版本验证的是指定 MotionResult 采样点或已执行 内置物理后端 离散积分步上的真实三角网格安全性。它不提供连续时间绝对无碰撞证明，不实现 BREP/NURBS 精确曲面距离、接触力、冲击、摩擦或齿面接触。
