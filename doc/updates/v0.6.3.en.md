# KinCheckAPI v0.6.3 update

v0.6.3 adds an auditable contact/friction capacity check. `ContactSpec` explicitly declares the contact normal, friction coefficient, contact area, allowable normal force, and allowable pressure. `check_contact_capacity()` decomposes an applied force into normal and tangential components and checks separation, the Coulomb friction cone, normal load, and pressure. It returns utilization for every declared limit and structured failure causes. The normal points in the direction of the compressive load; units are N, Pa, and m².

The E01 example adds `examples/dynamics_loaded_arm/verification/verify_contact.py` for a 10 N normal and 1 N lateral platform-guide load. It runs independently from the CADIR interface and static programs so geometry, physical-source, load, and contact-capacity failures remain distinguishable.

This contact API is a capacity check for a supplied force. It is not a contact-force solver and does not provide continuous contact response, collision impulse, restitution, contact deformation, stress, vibration, resonance, or fatigue life. Non-finite forces, non-unit normals, separation, and friction/pressure overuse return `validation_failed` or `failed`.
