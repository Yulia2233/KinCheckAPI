# KinCheckAPI v0.5.6 Update

v0.5.6 adds numerical inverse kinematics for the scalar joint backend already supported by KinCheckAPI. `solve_inverse_kinematics()` accepts a static `PoseTarget`, an initial joint guess, effective joint ranges, and typed `IKOptions`. It searches with forward poses, finite-difference Jacobians, and damped least-squares iterations.

The release adds `IKOptions`, `IKSolution`, and `IKSolutionSet`. Results distinguish `solved`, `unreachable`, `nonconverged`, `singular`, `invalid`, and `capability_failed`. Each candidate records its seed, final joint values, position/orientation errors, residual norm, iteration count, Jacobian rank, singular values, limit status, and structured issues. `multi_start_count` and `random_seed` provide deterministic finite multistart search; candidates are deduplicated before selecting `first`, `lowest_residual`, or `closest_to_initial`.

Every candidate is re-evaluated against the target pose, authored closure/transmission residuals, and effective joint ranges before it can appear in `solutions` or `selected_solution`. Unverified attempts remain in `attempts`. `IKSolutionSet` supports `to_dict()` and `from_dict()` round-trip.

This release intentionally supports only scalar `fixed`, `revolute`, and `prismatic` tree joints. `PoseTrajectory` driving, spherical/free/planar/cylindrical joints, collision-constrained IK, time-optimal IK, and a proof of globally complete multisolutions remain explicit capability boundaries or future work. Finite multistart improves solution discovery but cannot prove that no other solution exists.

Tests cover reachable targets, deterministic multistart, fixed-range unreachable targets, invalid inputs, PoseTrajectory and spherical-Joint capability boundaries, structured diagnostics, and result round-trip. Run before release:

```bash
.venv/bin/python -m pytest -q tests/test_v056_ik.py tests/test_v021_position_geometry.py tests/test_v021_analysis.py
.venv/bin/python -m pytest -q
```
