# KinCheckAPI v0.5.4

本预备版本把运动工况、求解配置和验收证据连成可复现闭环：新增 `MotionSegment` 分段驱动及重叠校验、home 初始状态选择、`KinematicSolveOptions`、后端能力报告、结构化积分步样本、`DriverTarget`/`DriverTrajectory`、严格的关节/组件/连接点结果过滤，以及 `check_driver_tracking()` 驱动跟踪报告。`completed` 仍只表示积分完成，必须单独检查驱动误差。

曲柄滑块验收程序位于 `examples/slider_crank/verification/verify.py`。CADIR 建模源位于 `examples/slider_crank/model/source/slider_crank.cadir.py`，并已生成 `slider_crank.scadpkg`、MJCF、mapping 和四个网格。当前环境只有 SimpleCADAPI 2.1.3b1，未满足 addon 门禁要求的 `>=2.1.3b3,<2.1.4`；源代码包含仅针对 b1 placement tick 缺陷的兼容归一化分支，安装 b3 后应移除该分支并重新导出。

验证脚本直接执行也输出 JSON；失败时包含结构化错误码、状态和证据，退出码为非零。

兼容性：旧的 Scenario 字段和 setter 保持不变；`solve_motion(options=None)` 的调用语义不变，新增选项必须使用 `KinematicSolveOptions`。
